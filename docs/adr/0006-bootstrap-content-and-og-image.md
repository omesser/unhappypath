# ADR-0006: Ship with stubs; seed projects from real repos; one static og:image

- **Date:** 2026-07-29
- **Status:** Accepted

## Context

Spec §5 says v1 ships with clearly-marked stub content that Oded swaps out. Spec §8 amends the
earlier no-OG-images rule to require **one** site-wide static 1200×630 `og:image`; no such
asset exists in the repo, and per-post generated images stay out of v1.

Biographical prose cannot be authored on Oded's behalf — inventing facts about a real person is
not an option. Public GitHub repositories, by contrast, are factual data, and `gh` is
authenticated as `omesser`.

## Decision

**Stubs, TODO-marked:** bio (with inline structure prompts, 150–350 words), three tagline
drafts to choose from, three example fun-links bullets, and a neutral SVG avatar placeholder.

*Revised during implementation:* `/contact` ships **no** placeholder email. `CONTACT_EMAIL` in
`src/consts.ts` starts empty and the page renders a TODO box instead of an address — a fake
`mailto:` is a broken link on the one page whose entire job is being reachable, and it would
have looked real enough to escape notice. Setting the constant turns the box into the link.

**Seeded from real data:** project cards are pre-filled from `gh repo list omesser` (name,
description, primary language → tags, URL) so curation is pruning rather than typing from
scratch. Five cards were seeded; spec §4.2 wants 4–8 curated. Social links use the real URLs
from spec §4.1.

**Demo posts:** two stub posts that exercise the Markdown surface — headings, code fence,
colocated image, raw `<iframe>` — so the reading layout is verifiable before real content lands.

**og:image:** a hand-authored SVG (site name, tagline, domain, in the site's font and palette)
rasterized **once** to `public/og.png` with `sharp`, which Astro already installs. The SVG
source is kept at `spec/og.svg` so it can be re-rendered if the tagline changes. Build-time
per-page generation (satori/resvg) was rejected as explicitly deferred by spec §8; leaving the
tag pointing at a missing file was rejected because link previews would stay blank.

## Consequences

- No fabricated biographical claims ship, at the cost of visible TODOs in v1.
- Every stub is greppable (`TODO`) so nothing placeholder-ish escapes to production unnoticed.
- `og.png` is a committed binary that must be regenerated by hand when the tagline is chosen.
- Two throwaway demo posts must be deleted once real posts exist.
